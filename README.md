# My Library

## Overview
A web application to search and display book information using the Open Library API.

## Features
- Search for books by title.
- View book cover, author, and publication details.
- Click on a book to see more information in a modal.

## Technologies Used
- HTML
- CSS
- JavaScript
- Open Library API

## Getting Started

### Prerequisites
A modern web browser (Chrome, Firefox, etc.).

### Installation
1. Clone or download this repository.
   ```bash
   git clone https://github.com/yourusername/my-library.git
   
2. Open `index.html` in your web browser.

### Usage
1. Type a book title into the search bar.
2. Click "Search" to see a list of matching books.
3. Click on a book to view detailed information in a modal.

## Demo
You can view a live demo of the application at the following link: [Library Demo.](https://library-eight-zeta.vercel.app/)

## API Reference
Data is fetched from the [Open Library API](https://openlibrary.org/developers/api).
